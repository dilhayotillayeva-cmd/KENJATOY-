# KENJATOY AI — Render web sayti

## Tez ishga tushirish
1. Ushbu ZIP ichidagi barcha fayllarni GitHub repository'ga yuklang.
2. Render.com saytida New + → Blueprint ni tanlang va GitHub repository'ni ulang (yoki Web Service yarating).
3. `OPENAI_API_KEY` environment variable'iga o'zingizning OpenAI API kalitingizni kiriting.
4. Deploy tugashini kuting va Render bergan `.onrender.com` manzilini oching.

## Muhim
- Sayt kodi tayyor, lekin Render'ga o'zingiz ulab deploy qilishingiz kerak; men hisobingizga kirib deploy qila olmayman.
- Chat va rasm yaratish uchun haqiqiy API kaliti kerak. API foydalanishi uchun to'lov bo'lishi mumkin.
- API kalitni HTML yoki GitHub kodiga yozmang. Uni faqat Render Environment'ga kiriting.
- API kalitini hech kimga yubormang.
